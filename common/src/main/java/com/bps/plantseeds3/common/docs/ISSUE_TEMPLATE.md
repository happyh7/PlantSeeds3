# Issue Templates

## Bug Report

```markdown
## Beskrivning
En tydlig och kortfattad beskrivning av vad buggen är.

## Steg för att reproducera
1. Gå till '...'
2. Klicka på '....'
3. Scrolla till '....'
4. Se felet

## Förväntat beteende
En beskrivning av vad du förväntade dig skulle hända.

## Screenshots
Om möjligt, lägg till screenshots för att hjälpa till att förklara problemet.

## Miljö
 - Android Studio: [version]
 - Kotlin: [version]
 - Gradle: [version]
 - Android SDK: [version]
 - Device/Emulator: [version]

## Loggar
Om möjligt, inkludera relevanta loggar.

## Övrig information
Lägg till någon annan kontext om problemet här.

## Checklista
- [ ] Jag har sökt efter liknande issues
- [ ] Jag har kontrollerat att det inte är ett lokalt problem
- [ ] Jag har inkluderat all relevant information
```

## Feature Request

```markdown
## Problem
En tydlig och kortfattad beskrivning av problemet eller behovet.

## Lösning
En beskrivning av den önskade funktionaliteten.

## Alternativ
En beskrivning av eventuella alternativa lösningar eller funktioner du har övervägt.

## Användningsfall
Beskriv specifika användningsfall där denna funktion skulle vara användbar.

## Exempel
Om möjligt, inkludera exempel på hur funktionen skulle kunna användas.

## Checklista
- [ ] Jag har sökt efter liknande feature requests
- [ ] Jag har motiverat varför denna feature behövs
- [ ] Jag har inkluderat exempel på användning
```

## Dokumentation

```markdown
## Problem
En tydlig och kortfattad beskrivning av vad som saknas eller är otydligt i dokumentationen.

## Förslag
En beskrivning av hur dokumentationen kan förbättras.

## Kontext
Vilken del av dokumentationen gäller det?

## Checklista
- [ ] Jag har sökt efter relevant information i dokumentationen
- [ ] Jag har förtydligat var informationen saknas
- [ ] Jag har föreslagit specifika förbättringar
```
